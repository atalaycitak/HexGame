# Hex Board Game
Hex Board Game, a strategic and engaging board game built using JavaFX. The game revolves around a hexagonal grid where players must connect opposite sides with an unbroken chain of their pieces to win. Inspired by the classic Hex game, this version introduces a smooth and intuitive interface for a seamless gaming experience.

# Features
User-Friendly UI: Built with JavaFX, providing a visually appealing and easy-to-use interface.
Two Player Mode: Enjoy a competitive game against a friend locally.
Customizable Board Size: Choose from different grid sizes for varied gameplay.
Switch: You can switch your first move with your opponent.


# How to Play
The game takes place on a hexagonal grid. Players take turns placing their pieces on the grid.
The objective is to connect your assigned edges with a continuous path of your pieces.
The first player to successfully connect their two sides wins.
